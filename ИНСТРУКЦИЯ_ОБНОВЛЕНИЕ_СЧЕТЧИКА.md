# Инструкция: Обновление счётчика мест

**Цель:** Синхронизировать количество свободных мест из Google Sheets на сайт

---

## Автоматический способ (30 секунд)

### Запустить скрипт:

```bash
cd "/Users/azaryarozet/Library/Mobile Documents/com~apple~CloudDocs/○/olga/olgaroset.ru"
python3 sync_seats.py
```

**Что делает скрипт:**
1. Читает значение из Google Sheets (ячейка G2)
2. Обновляет `chl/seats.json`
3. Коммитит и пушит в Git
4. GitHub Pages автоматически обновится через 2-3 минуты

---

## Автоматизация (опционально)

### Настроить cron для автоматического обновления каждые 5 минут:

```bash
crontab -e
```

Добавить строку:

```
*/5 * * * * cd "/Users/azaryarozet/Library/Mobile Documents/com~apple~CloudDocs/○/olga/olgaroset.ru" && /usr/local/bin/python3 sync_seats.py >> sync_seats.log 2>&1
```

**Результат:** Счётчик будет автоматически синхронизироваться каждые 5 минут.

## Проверка

---

## Примечания

- Google Sheets считает автоматически (формула в G2: `=25-F2`)
- F2 = количество занятых мест (`=COUNTA(A2:A26)`)
- При каждой новой регистрации в столбце A, G2 автоматически уменьшается

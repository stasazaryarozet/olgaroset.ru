**Дата:** 19 ноября 2025, 10:45

---

## Причина

Изображения находятся на `/Volumes/OlgaWork/` (NAS), к которым браузер не имеет доступа.

---

## Решение

### Вариант 1: Плейсхолдеры (текущее) ✅

**Что сделано:**
- Интерфейс теперь показывает плейсхолдеры с:
  - Именем файла
  - Размерами (dimensions)
  - Источником (nas_drawings, google_drive, etc.)

**Использование:**
1. Обновить страницу: http://localhost:8000/review.html
2. Отобрать работы по именам файлов
3. Сохранить `works_selected.yaml`

**Плюс:** Работает без NAS  
**Минус:** Нет визуального превью

---

### Вариант 2: Копировать превью локально (рекомендуется)

```bash
# Создать папку для превью
mkdir -p "/Users/azaryarozet/Library/Mobile Documents/com~apple~CloudDocs/○/olga/olgaroset.ru/works/preview_thumbs"

# Скопировать все файлы с NAS (если подключен)
if [ -d "/Volumes/OlgaWork" ]; then
    rsync -av --progress \
        "/Volumes/OlgaWork/Мои рисунки/" \
        "/Users/azaryarozet/Library/Mobile Documents/com~apple~CloudDocs/○/olga/olgaroset.ru/works/preview_thumbs/" \
        --include='*.jpg' --include='*.jpeg' --include='*.JPG' --include='*.JPEG' \
        --exclude='*'
    
    echo "✅ Превью скопированы"
else
    echo "❌ NAS не подключен (/Volumes/OlgaWork)"
fi
```

Затем обновить `review.html` для использования локальных превью.

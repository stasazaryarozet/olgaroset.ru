# Works: Инструмент для отбора

Создан веб-интерфейс для отбора работ из 199 найденных файлов.

## Использование

1. **Запустить локальный сервер:**
```bash
cd "/Users/azaryarozet/Library/Mobile Documents/com~apple~CloudDocs/○/olga/olgaroset.ru/works"
python3 -m http.server 8000
```

2. **Открыть в браузере:**
```
http://localhost:8000/review.html
```

3. **Отобрать работы:**
- Просмотреть все 199 файлов
- Кликнуть на работы для отбора (выделяются синим)
- Нажать "Сохранить отбор"
- Скачается `works_selected.yaml`

4. **Заполнить метаданные:**
В `works_selected.yaml` для каждой работы указать:
```yaml
  - id: "018"
    path: "..."
    title: "Название работы"          # ← заполнить
    year: 2023                         # ← заполнить
    technique: "Акварель, бумага"      # ← заполнить
    size: "30×40 см"                   # ← заполнить
    context: "История создания..."     # ← заполнить
```

5. **Экспортировать в галерею:**
```bash
python3 export_selected.py
# Создаст work-018.html, work-019.html, ...
# Добавит в index.html
```
